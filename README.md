# Mini CRM - Client Lead Management System

A simple yet functional Client Lead Management System (Mini CRM) designed for agencies, freelancers, and startups. This tool helps businesses capture leads from their website, track their status, add follow-up notes, and visualize conversion data through a secure admin dashboard.

## 🚀 Features

- **Lead Capture:** Modern, responsive contact form for potential clients.
- **Secure Admin Panel:** Protected login to prevent unauthorized access to lead data.
- **Lead Tracking:** Manage status transitions (New → Contacted → Converted).
- **Follow-up System:** Add timestamped notes to each lead for business reference.
- **Analytics Dashboard:** - Real-time lead count.
  - Interactive Pie Chart (Weekly/Monthly filters) powered by Recharts.
- **Search & Filter:** Quickly find leads by name or email.
- **Confirmation Protection:** Two-factor confirmation for deleting leads.
- **Dark Mode Aesthetic:** Consistent Deep Navy/Slate professional theme throughout.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Recharts, Axios.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB Atlas (Mongoose ODM).
- **Styling:** Modular CSS3 (Custom Dark Theme).
